================================================================
  MOVIE BOOKING SYSTEM – REST API ENDPOINTS & PAYLOADS
  Base URL: http://localhost:8080/movie-booking-system/api
================================================================

All requests and responses use Content-Type: application/json
Dates use format: yyyy-MM-dd'T'HH:mm:ss
IDs are UUID strings (auto-generated by the server)

----------------------------------------------------------------
  1. THEATRE ENDPOINTS
----------------------------------------------------------------

1.1  GET /api/theatres
     Description : List all theatres
     Request Body: (none)
     Response 200:
     [
       {
         "id"         : "uuid-string",
         "name"       : "PVR Cinemas",
         "location"   : "Phoenix Mall, Mumbai",
         "totalSeats" : 200,
         "createdAt"  : "2025-06-01T10:00:00",
         "updatedAt"  : "2025-06-01T10:00:00"
       }
     ]

1.2  GET /api/theatres/{id}
     Description : Get a single theatre by ID
     Request Body: (none)
     Response 200:
     {
       "id"         : "uuid-string",
       "name"       : "PVR Cinemas",
       "location"   : "Phoenix Mall, Mumbai",
       "totalSeats" : 200,
       "createdAt"  : "2025-06-01T10:00:00",
       "updatedAt"  : "2025-06-01T10:00:00"
     }
     Response 404: { "error": "Theatre not found" }

1.3  POST /api/theatres
     Description : Create a new theatre
     Request Body:
     {
       "name"       : "INOX Multiplex",       (required)
       "location"   : "Lulu Mall, Kochi",     (required)
       "totalSeats" : 150                     (optional, default: 100)
     }
     Response 201:
     {
       "id"         : "uuid-string",
       "name"       : "INOX Multiplex",
       "location"   : "Lulu Mall, Kochi",
       "totalSeats" : 150,
       "createdAt"  : "2025-06-01T10:00:00",
       "updatedAt"  : "2025-06-01T10:00:00"
     }
     Response 400: { "error": "Fields 'name' and 'location' are required" }

1.4  PUT /api/theatres/{id}
     Description : Update an existing theatre
     Request Body:
     {
       "name"       : "INOX Multiplex Updated",  (required)
       "location"   : "Lulu Mall, Kochi",        (required)
       "totalSeats" : 180                        (optional)
     }
     Response 200: (updated theatre object)
     Response 404: { "error": "Theatre not found" }

1.5  DELETE /api/theatres/{id}
     Description : Delete a theatre (cascades to movies and bookings)
     Request Body: (none)
     Response 204: (no content)
     Response 404: { "error": "Theatre not found" }

         "title"          : "Inception",
         "genre"          : "Sci-Fi",

         "durationMin"    : 148,

         "ticketPrice"    : 250.00,
         "availableSeats" : 80,

         "updatedAt"      : "2025-06-01T10:00:00"

     Description : Get a single movie by ID

2.5  PUT /api/movies/{id}

     Request Body: (same as POST, all fields required)
     Response 200: (updated movie object)

2.6  DELETE /api/movies/{id}
     Description : Delete a movie (cascades to bookings)
     Request Body: (none)

  4. BOOKING ENDPOINTS
----------------------------------------------------------------

4.1  GET /api/bookings
     Description : List all bookings
     Query Params: userId={uuid}  (optional – filter by user)
     Request Body: (none)
     Response 200:
     [
       {
         "id"           : "uuid-string",
         "userId"       : "uuid-string",
         "movieId"      : "uuid-string",
         "seatsBooked"  : 2,
         "totalAmount"  : 500.00,
         "status"       : "CONFIRMED",
         "bookedAt"     : "2025-06-01T12:00:00",
         "cancelledAt"  : null,
         "userName"     : "Rahul Sharma",
         "movieTitle"   : "Inception",
         "theatreName"  : "PVR Cinemas",
         "showTime"     : "2025-06-15T18:30:00"
       }
     ]

4.2  GET /api/bookings/{id}
     Description : Get a single booking by ID
     Request Body: (none)
     Response 200: (single booking object as above)
     Response 404: { "error": "Booking not found" }

4.3  GET /api/bookings?userId={userId}
     Description : List all bookings for a specific user
     Request Body: (none)
     Response 200: (array of booking objects)

4.4  POST /api/bookings
     Description : Create a new booking
                   - Deducts (seatsBooked × ticketPrice) from user wallet
                   - Decreases movie's availableSeats
                   - All three operations are atomic (single transaction)
     Request Body:
     {
       "userId"      : "uuid-string",   (required)
       "movieId"     : "uuid-string",   (required)
       "seatsBooked" : 2               (required, >= 1)
     }
     Response 201: (created booking object)
     Response 400: { "error": "Required fields: userId, movieId, seatsBooked" }
     Response 402: { "error": "Insufficient wallet balance. Required: 500.0, Available: 200.0" }
     Response 404: { "error": "User not found" }
     Response 404: { "error": "Movie not found" }
     Response 409: { "error": "Not enough seats available. Available: 3" }

4.5  PUT /api/bookings/{id}/cancel
     Description : Cancel a confirmed booking
                   - Refunds totalAmount back to user's wallet
                   - Restores seatsBooked to movie's availableSeats
                   - All three operations are atomic (single transaction)
                   - Only CONFIRMED bookings can be cancelled
     Request Body: (none / empty body)
     Response 200:
     {
       "id"           : "uuid-string",
       "userId"       : "uuid-string",
       "movieId"      : "uuid-string",
       "seatsBooked"  : 2,
       "totalAmount"  : 500.00,
       "status"       : "CANCELLED",
       "bookedAt"     : "2025-06-01T12:00:00",
       "cancelledAt"  : "2025-06-02T09:00:00",
       "userName"     : "Rahul Sharma",
       "movieTitle"   : "Inception",
       "theatreName"  : "PVR Cinemas",
       "showTime"     : "2025-06-15T18:30:00"
     }
     Response 404: { "error": "Booking not found" }
     Response 409: { "error": "Booking is already cancelled" }

================================================================
  BUSINESS RULES
================================================================

  1. Each movie belongs to exactly one theatre (theatreId is required).
  2. Booking deducts (seatsBooked × ticketPrice) from user wallet atomically.
  3. If wallet balance is insufficient, booking is rejected (HTTP 402).
  4. If available seats are insufficient, booking is rejected (HTTP 409).
  5. Cancellation refunds the full totalAmount to the user's wallet.
  6. Cancellation restores the seats back to the movie's availableSeats.
  7. Only CONFIRMED bookings can be cancelled; re-cancelling returns HTTP 409.
  8. Deleting a theatre cascades to its movies and all related bookings.
  9. Deleting a user cascades to all their bookings.
  10. passwordHash is never returned in any API response.
